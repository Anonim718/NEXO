# NEXO Voice System

NEXO is intended to use a hybrid voice architecture.

## Offline mode

Used for essential commands that should work without an internet connection.

Examples:
- Wake / stop
- Basic movement
- Status
- Emergency stop

## Online mode

Used for richer conversation and AI-assisted commands when connectivity is available.

## Goal

The robot should remain useful when offline while gaining more advanced conversational abilities when an online connection is available.
